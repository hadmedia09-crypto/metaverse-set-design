# METAVERSE — Beyond the Frames

Set design & spatial pack for a Meta networking and co-creation event at The St. Regis, Lower Parel, Mumbai (200 guests).

**Designed by Danial Sayed, Kaloni Dsouza, Peehu Gupta & Jeel Gandhi**

## Contents
- `index.html` — animated showcase website (open in any browser, or view via GitHub Pages)
- `assets/` — renders, technical drawing sheets, styles and scripts
- `Metaverse-Set-Design-Pack.pdf` — full 42-page set design pack: scaled zone drawings, 3D axonometric, stage, lighting, AV, power, safety, run of show and BOQ

> Hall dimensions and BOQ figures are design estimates and must be verified on site survey.
